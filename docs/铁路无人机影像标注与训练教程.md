# 铁路无人机影像部件识别：从零构建数据集并训练模型

本教程面向一个真实目标：**用无人机巡检影像，训练一个能识别铁路部件（扣件、轨枕、绝缘子、接触网支柱等）的检测模型**。全程在 figtools 内完成，不需要 Python 命令行（可选高级步骤除外）。

## 1. 先理解整体流程

```
无人机影像 → 定义类别 → 逐图标注 → sidecar 文件 → 数据集划分 → 快照导出 → YOLO 训练 → 检测验证
```

几个关键概念先说清楚：

| 概念 | 含义 |
|---|---|
| **类别（class）** | 你要识别的部件种类，如"扣件""轨枕"。ID 从 0 开始，训练时按这个顺序编号 |
| **标注（annotation）** | 一个类别 + 一个形状（矩形或多边形），对应图里的一个部件实例 |
| **sidecar** | 每张图片旁边的 `.annotations.json`，存这张图的全部标注。**这是数据集的真相来源** |
| **快照（snapshot）** | 导出目录，含 `images/`、`annotations/`、`splits/`、`dataset.json`，训练脚本直接读它 |
| **mAP50** | 模型评价指标，0~1，越高越好；只跑几轮时低是正常的 |

**重要原则**：先定好类别再标注。中途改类别 ID 会让已有标注错位。

## 2. 准备影像和目录

### 2.1 影像要求

- 格式：PNG / JPG / BMP（figtools 均可读）
- 分辨率：无人机原始尺寸即可（如 3840×2160）。软件内部会自动生成预览，标注坐标按预览图记录，导出时换算回原尺寸
- 数量：目标检测建议**每类至少 100~200 个实例**。例如要识别 5 类部件，先准备 300~500 张图比较稳妥

### 2.2 目录组织

建一个纯英文路径的数据集目录（中文路径软件也支持，但英文更省事）：

```
D:/rail_dataset/
├── images/
│   ├── rail_0001.jpg
│   ├── rail_0002.jpg
│   └── ...
```

**不要**把标注文件和图片混放——sidecar 会自动写在图片同目录，文件名是 `图片名.annotations.json`。

### 2.3 导入影像

1. 打开 figtools（双击 `run_figtools.bat`）
2. 菜单 **文件 → 打开图像…**（`Ctrl+O`），选中一张图开始；或把多张图**直接拖进窗口**——每开一张会出现一个文档标签页
3. **标注一整个文件夹**：文件 → 「打开序列（文件夹）…」，选中 `images` 目录，软件按文件名排序把全部图片打开成标签页。之后用 `A` / `D` 逐图切换，标注自动保存，这是最顺手的批量标注方式

> 提示：顶部的文档标签栏支持同时打开多张图，每张图各自保留处理链和标注，切换不丢失。
> **重要**：打开一张图片时，软件会自动读取它旁边的 `.annotations.json`。所以已经标过的图重新打开会自动显示标注，没标过的新图则是空白——这正是逐图标注整个文件夹的正确工作方式。你定义的类别列表会一直保留，不需要每张图重新设。

## 3. 定义部件类别

这是建立数据集的**第一步**，也是最容易被忽略的一步。默认类别是"区域/目标/参考/忽略"，必须换成你的铁路部件。

### 3.1 打开类别管理

1. 左侧切到 **标注** 页（左侧"项目"树点"标注"，或顶部 Ribbon 的"标注"页签）
2. 在"类别"列表下方点 **「管理类别…」**

### 3.2 设置你的类别

在弹出的对话框里：

- 每一行是一个类别；**ID 列自动按行号从 0 递增**，这就是 YOLO 训练用的类别编号
- 双击"类别名称"输入框改名
- 点"颜色"按钮给每类挑一个区分度高的颜色
- 用"+ 添加类别"增加行，"删除选中"移除行

以铁路巡检为例，一套合理的类别：

| ID | 类别名称 | 说明 |
|---|---|---|
| 0 | 扣件 | 轨道扣件，目标小、数量多 |
| 1 | 轨枕 | 混凝土/木轨枕 |
| 2 | 绝缘子 | 接触网绝缘子 |
| 3 | 支柱 | 接触网支柱 |
| 4 | 信号机 | 沿线信号设备 |
| 5 | 异物 | 侵入限界的异物（可选） |

**命名建议**：用英文或拼音更稳妥（如 `fastener`、`sleeper`、`insulator`），避免后续训练时编码问题；名称里不要有空格，可用下划线。

### 3.3 保存

点「保存」，类别列表立即更新。之后所有新建标注都会用当前选中的类别。

> 如果你已经在旧类别下标了一些图，改类别会影响那些标注的含义——**改类别最好在标注之前完成**。需要恢复时，标注文件（JSON）里存有完整的 classes 定义，用「载入」可还原。

## 4. 逐图标注

### 4.1 选择工具和类别

- **选类别**：在左侧类别列表点一下，或直接按数字键 `1`~`9`（对应列表第 1~9 类）
- **选工具**：左侧"工具"行有 7 个按钮，或按快捷键：

| 快捷键 | 工具 | 用途 |
|---|---|---|
| `V` | 选择 | 移动/编辑已有标注 |
| `R` | 矩形 | 框出目标（检测任务最常用） |
| `C` | 多边形 | 精确勾勒不规则部件轮廓 |
| `W` | 魔棒 | 单击选相似区域 |
| `G` | 框选分割 | 拖框让 GrabCut 自动抠图 |
| `P` | 取色 | 查看像素 RGB/灰度 |
| `M` | 测距 | 两点间距离 |

### 4.2 矩形标注（最常用）

检测任务用矩形就够了，速度快：

1. 按 `R` 切到矩形工具
2. 在目标左上角**按下鼠标，拖到右下角松开**
3. 一个带类别颜色和名称标签的框就出现了

**画得准的要点**：
- 框要**紧贴目标边缘**，不要留太多背景
- 小目标（如扣件）也要框完整，别裁掉一角
- 被遮挡的部件：按"能看到的部分"框，或按完整范围框（全项目保持一致）

### 4.3 多边形标注（轮廓精确时用）

适合绝缘子、不规则部件：

1. 按 `C` 切到多边形工具
2. 沿目标轮廓**逐点单击**
3. 双击或按 `Enter` 闭合

**技巧**：
- 点不用太多，拐角处点即可（直线段中间不需要点）
- 点错了按 `Esc` 取消重画

### 4.4 编辑已有标注

按 `V` 切到选择工具后：

- **点选**一个标注 → 高亮并显示控制点
- **拖动**标注内部 → 整体移动
- **拖矩形四角** → 缩放
- **拖多边形顶点** → 调整轮廓
- **双击多边形的边** → 在该处插入新顶点
- **`Delete`** → 删除选中的标注

这一步很重要——**标注不需要一次画对，先框大概位置，再微调**是最快的工作流。

### 4.5 保存

- 标注变更后 **1.2 秒自动保存**到图片旁的 `.annotations.json`（只对有磁盘路径的真实图片，示例图不写）
- 也可以按 `Ctrl+S` 立即保存
- 状态栏文件名后会出现 `•` 表示已写入

## 5. 用半自动工具加速

一个一个手框几百张图很累。软件提供两条免模型的半自动路径，以及一条模型辅助路径。

### 5.1 魔棒（W）——适合色差明显的部件

1. 按 `W`
2. 在目标上**单击**
3. 软件选出颜色相似的连通区域，显示半透明预览多边形
4. 调整左侧"容差"滑块（5~100）：值越大选区越大；选多了就调小，选少了调大
5. 满意就点 **「应用分割」**，把预览转成标注；不满意点「取消」

适合：天空背景下的浅色部件、颜色均匀的标牌等。

### 5.2 框选分割 GrabCut（G）——通用目标抠图

1. 按 `G`
2. **拖拽一个框**把目标圈住（框要比目标略大一圈）
3. 内部用 GMM 颜色模型 + 图割自动抠出前景，显示预览
4. 点「应用分割」转标注

这是效果最好的免模型方法。适合：背景复杂但目标颜色/纹理与背景有区别的场景。

### 5.3 模型辅助——分割结果转标注

如果你已经训练过 yolo-seg 分割模型并载入：

1. 模型 → 分割当前图像
2. 左侧点 **「分割结果 → 标注」**，所有实例一次性转成多边形标注

### 5.4 三种方法怎么选

| 场景 | 推荐 |
|---|---|
| 目标小、密集、数量多（扣件） | 手框矩形 + 快捷键，反而最快 |
| 目标颜色与背景差异大 | 魔棒 |
| 目标清晰但背景杂乱 | GrabCut |
| 已有分割模型、大批量同类目标 | 模型辅助 |

**别迷信自动工具**：半自动结果一定要人工检查边界，尤其是小目标。

## 6. 质量控制与检查

### 6.1 标注列表核对

左侧"标注"列表显示当前图的所有标注（`01 区域·矩形` 这种格式）。逐个点选可以定位到对应标注。

### 6.2 常见问题清单

标注一批图后，回头抽查，重点看：

- [ ] 有没有漏标的明显目标
- [ ] 框是否过大（含太多背景）或过小（裁掉目标）
- [ ] 类别有没有选错（例如把绝缘子标成支柱）
- [ ] 同类目标的标注标准是否一致（遮挡、模糊目标的处理方式要统一）
- [ ] 极小的目标（< 10 像素）是否值得标——通常不标

### 6.3 一致性比数量更重要

模型学的是"你标注的规律"。如果同一类部件有时框整体、有时只框一半，模型会学乱。**宁可少标一些，也要标准统一**。

## 7. 数据集划分与导出

标完一批图后，把它们变成训练能用的数据集。

### 7.1 选择图片目录

1. 左侧切到 **数据集** 页
2. 点 **「选择图片目录…」**，选中 `D:/rail_dataset/images`
3. 软件会扫描目录，自动识别每张图旁边的 `.annotations.json`，显示图片数、标注数、类别统计
4. 检查"警告"列表：有没有图片缺标注、标注文件解析失败等

### 7.2 划分训练/验证/测试集

1. 在"划分"区设置比例，例如 **训练 70% / 验证 15% / 测试 15%**
2. 勾选 **「按类别分层」**（重要！避免某个稀有类别全落到训练集，导致验证集里根本没有它）
3. 设一个随机种子（默认 2026，固定种子保证结果可复现）
4. 点 **「划分数据集」**

### 7.3 导出快照

1. 点顶部或数据集页的 **「导出快照」**
2. 选一个父目录（如 `D:/rail_dataset/`）
3. 软件生成 `<目录名>-v1/` 文件夹，内含：
   ```
   rail_dataset-v1/
   ├── images/        训练/验证/测试图片副本
   ├── annotations/   对应的标注 JSON
   ├── splits/        划分清单
   └── dataset.json   数据集清单
   ```

这个快照就是训练脚本的输入。

## 8. 训练模型

### 8.1 打开训练工作台

菜单 **模型 → 训练模型…**（`Ctrl+T`）。训练界面嵌入主窗口，不再弹独立窗口。

### 8.2 配置训练

训练页有"配置"和"实时监控"两个页签。在"配置"页：

**数据与输出**
- **数据**：选刚才导出的快照目录（含 `dataset.json` 的那层）
- **输出**：模型保存目录，如 `D:/rail_dataset/model`
- **Python**：解释器路径（本机已配置好，一般不用改）

**模型与训练参数**
- **任务**：选「YOLO 检测」
- **YOLO 版本**：`yolo11n`（nano，最快）起步；数据多、要精度可以选 `yolo11s`/`yolo11m`
- **架构/尺寸**：默认 640 即可；小目标多可以调到 960（更慢但更容易检出小部件）
- **轮数（epochs）**：
  - 快速验证：**30~50 轮**
  - 正式训练：**100~300 轮**
- **批大小（batch）**：显存够就 16，不够改 8
- **学习率**：默认即可
- **设备**：有 NVIDIA 显卡选 `cuda`，否则 `cpu`（CPU 会慢很多）

### 8.3 开始训练

点「开始训练」，切到 **「实时监控」** 页签可以看：

- 左侧：完整日志（每轮的 loss、mAP50、mAP50-95）
- 右上：每轮指标表
- 右下：loss / mAP 双轴曲线

训练完成后会提示模型目录和最终 mAP50。

### 8.4 训练要多久

取决于图片数量、轮数、硬件。几百张图 + 100 轮 + CUDA，通常几十分钟到几小时。**第一次先用 30 轮跑通流程**，确认整体没问题再正式训练。

## 9. 验证与推理

### 9.1 载入模型

菜单 **模型 → 载入模型…**，选训练输出目录里的模型包。

### 9.2 检测新图

打开一张没标过的无人机影像，菜单 **模型 → 检测当前图像**（`Ctrl+D`）。

检测框会叠加在画布上，带类别名和置信度。重点看：

- 有没有漏检（尤其是小扣件）
- 有没有误检（把道砟、标线当成部件）
- 类别有没有混淆

### 9.3 迭代改进

检测结果不理想时的排查顺序：

1. **数据量**：每类实例够不够 100~200 个
2. **标注质量**：框是否一致、是否漏标
3. **小目标**：图像尺寸是否太小，能否提高训练尺寸到 960
4. **训练轮数**：是否欠拟合（loss 还没降稳）
5. **类别平衡**：是不是某类样本远少于其他类

然后针对性补标数据、重新划分、再训练。这是一个循环，通常要做 2~3 轮。

### 9.4 导出论文图表

如果需要写论文或报告，用：

```
python scripts/make_paper_figures.py <results.csv目录> -o <输出目录>
```

生成 300 DPI 的 PNG 和矢量 PDF 训练曲线、指标表格（支持中英文标签）。

## 10. 常见问题

**Q：标注文件存在哪里？**
每张图片旁边的 `图片名.annotations.json`。移动图片时记得一起移动，否则数据集扫描会认为它没标注。

**Q：能中途改类别吗？**
能，但已有标注的 `class_id` 会指向新类别，含义会变。**最好标注前定好类别**。确实要改，先备份标注文件。

**Q：一张图里有几百个小扣件，一个个框太慢？**
优先用 GrabCut 或模型辅助；也可以用矩形工具快速连框——先框完所有同类目标，最后统一检查。熟练后比自动工具还快。

**Q：无人机图太大（4000×3000），标注卡吗？**
软件内部生成预览标注，坐标自动换算，不会卡。训练时脚本会按需缩放。

**Q：类别 ID 是从 0 还是 1 开始？**
从 0 开始。"管理类别"对话框会自动按行号编号，不用手动填。

**Q：训练报"没有训练图片"？**
检查快照目录里 `dataset.json` 是否存在、划分后 train 集是否为空（可能是图片太少或划分比例设错）。

**Q：mAP50 一直很低？**
先确认流程：用 30 轮跑通 → 检查标注质量 → 增加数据 → 增加轮数。8 张图训练 1 轮 mAP50=0 是正常的，不是 bug。
