# figtools UI 布局概念稿

**状态：** 高保真交互概念稿，尚未落入 Qt 实现。  
**入口：** 直接打开 `figtools-redesign.html`；`assets/` 需与 HTML 同目录。  
**覆盖：** 处理、标注、数据集、训练、推理五个工作区；深色 / 浅色主题；`Ctrl+K` 命令面板；hash 路由。

## 设计方向：精密仪器

figtools 的核心资产是图像与测量结果，界面应当像一台校准过的仪器，而不是一堆控件的集合。

- **画布优先**：任何工作区都先让图像/数据占据视觉中心，面板退到边缘。
- **单一强调色**：青绿色只表示“当前、可执行、已选中”；陶土色只用于标注数据；鼠尾草绿、雾蓝、梅色只做类别区分。
- **8pt 网格**：间距、行高、控件高度统一到 4 / 8 / 12 / 16 / 24 / 32。
- **一屏一个主操作**：主按钮全屏最多一个，其余降为 ghost / link。
- **深色画布恒定**：即使浅色主题，图像画布仍为深色，避免改变用户对像素的判断。

## 页面要点

- **处理**：左侧处理链 + 中间前后对比 + 右侧检查器；步骤行用序号、名称、参数摘要和开关，不堆图标。
- **标注**：顶部工具条只保留选择/矩形/多边形/魔棒/GrabCut/取色/测距；左侧类别 + 标注列表；右侧选中标注的几何与操作。
- **数据集**：左侧数据源、划分、警告；中间 4 列资产卡；右侧概览、训练前检查、快照。
- **训练**：任务类型 → 数据与输出 → 超参数 → 运行监视；运行中只保留“停止训练”作为危险操作。
- **推理**：模型、阈值、检测结果三段式检查器；画布检测框按类别着色，标签用深色底保证在浅色图像上可读。

## Qt 落地映射（建议）

- `gui/theme.cpp`：把上方 token 固化为 `ThemeTokens` 结构，禁止页面内散落颜色常量。
- `gui/main_window.cpp`：新增 `48px` 顶栏与 `52px` 模式栏；左右 dock 用 `QDockWidget` 固定 248 / 288；输出坞用 `QDockWidget` 折叠到 30。
- `gui/image_canvas.cpp`：画布背景恒为深色；缩放 HUD 与图像分离，避免重绘整幅图。
- 主操作按钮统一 `PrimaryButton` / `GhostButton` / `DangerButton` 三类，页面只允许一个 primary。
- 标注标签使用深色 chip + 类别色边框，避免在浅色标定图上对比度不足。

## 交互说明

- `#process` / `#annotation` / `#dataset` / `#training` / `#inference` 直达工作区。
- `?theme=light` 预览浅色主题。
- `Ctrl+K` 打开命令面板。
- 右上“设计说明”打开 420 px 规范抽屉；输出坞可展开/收起；检查器 tabs 可切换。
