设计说明
precision instrument · v1

五条原则

01画布优先：图像是主角，UI 只做安静的框架。
02单一强调：全界面只有一个青绿 accent；标注数据才用陶土色。
038pt 节奏：间距、行高、控件高度全部落在 4 / 8 的倍数上。
04层级靠字号与留白，不靠阴影和渐变。
05一屏一个主按钮；其余动作降为 ghost 或图标。

组件状态

  • 控件高度：紧凑 28px，标准 32px；行高 30/36px。
  • 按钮：primary 实心、ghost 描边、link 纯文字；hover 只提亮一级。
  • 选中：2px 左侧 accent 条 + surface-2 底；不使用大面积高亮。
  • 焦点：1px accent 外框；键盘优先，所有动作有快捷键。
  • 动效：120ms 悬停、180ms 面板；不做弹跳与缩放。

Qt 落地映射

  • gui/theme.cpp：把上方 tokens 落成两套 Palette，QSS 只引用语义 key。
  • Ribbon：90px 三段式改为 52px 单行模式栏，图标 18px + 单行文字。
  • MainWindow：拆出 workspace / annotation / model / ribbon 控制器，主窗口只做装配。
  • 检查器：按选中对象切换面板，删除空的折叠 section。
  • 输出坞：默认 30px 单行，展开 168px；状态栏只留 3 个关键指标。
